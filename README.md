
## 🚀 Features

- Set custom reminder intervals in minutes
- Play a `.wav` audio file along with the notification
- Option to run once or on a repeating interval
- Desktop notifications with action support

## ⚙️ Usage

Run using `cargo run` with the following options:
cargo run -- -i <interval_in_minutes>
cargo run -- -i <interval_in_minutes> -a <path_to_audio.wav>
cargo run -- -i <interval_in_minutes> -a <path_to_audio.wav> -o
